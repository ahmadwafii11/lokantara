# lokantara
indonesian trip connected by public transportation

- git clone https://github.com/ahmadwafii11/lokantara
- cd lokantara
- git switch frontend
- npm install -g pnpm
- pnpm install
- pnpm add react-router-dom
- pnpm add -D tailwindcss@latest @tailwindcss/vite@latest
- pnpm add lucide-react
- pnpm add @fontsource-variable/outfit
